
# **MY BLOG – HTML and CSS Project**

### **Overview**
**MY BLOG** is a single-page blog website created using HTML and CSS. The page displays three blog posts with a clean and minimalistic layout. It is designed to present content clearly with a focus on readability.

---

## **Features**
- **Single Page Layout**: The entire blog is displayed on one page, featuring three different blog posts.
- **Clean and Simple UI**: Minimalistic design with a focus on content readability.
- **Custom Styling**: Handcrafted CSS for layout, typography, and blog post presentation.

---

## **Tech Stack**
- **Frontend**: 
  - HTML5 for structure
  - CSS3 for styling
